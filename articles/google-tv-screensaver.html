How to change the screensaver on Google TV and Android TV

Google TV and Android TV handle screensavers differently, and the setting most people look for — pick any installed app as the screensaver — is hidden on Google TV. Here is what works on each, in order of how much effort it takes.

Updated 20 October 2026 For Google TV & Android TV

Google TV: Ambient Mode is the screensaver

On Google TV there is no "screensaver" menu. What idles on screen is Ambient Mode, and Google reserves it for its own sources.

Go to Settings → System → Ambient mode → Source. You get three choices: Google Photos, Art gallery (Google's own curated set), and an Experimental option. Third-party apps do not appear in that list, which is the single most common reason people conclude their screensaver app is broken when it is installed correctly.

Android TV: the classic screensaver menu

Older Android TV builds keep the standard Android daydream picker. Go to Settings → Device Preferences → Screen saver. Any installed app that registers a DreamService shows up here, so you can select it directly. You can also set how long the TV waits before it starts.

Using a third-party screensaver on Google TV

Two routes work, and neither requires rooting the TV.

A launcher that exposes the setting

Replacement launchers such as Projectivy Launcher or FLauncher add a screensaver override that Google TV itself does not offer. Install one, then look for Settings → Screensaver Override and pick the app you want.

One ADB command

If you would rather not change launcher, you can set it once over ADB. First enable developer options: Settings → System → About, then click Android TV OS build seven times. Then turn on Wireless debugging under Developer options, and from a computer on the same network:

adb connect <tv-ip>:5555
adb shell settings put secure screensaver_components <package>/<service>
adb shell settings put secure screensaver_enabled 1

Test it immediately rather than waiting for the idle timer:

adb shell cmd dreams start-dreaming

This survives reboots. It does not always survive a system update, so keep the command somewhere you can find it again.

Turning the screensaver off

On Google TV, Settings → System → Ambient mode and set the timer to Off, or set the source to something you do not mind seeing. On Android TV, Settings → Device Preferences → Screen saver → When to start and choose Never. Note that many TVs have a separate panel-level sleep timer; turning off the screensaver does not stop the TV switching itself off.

Common questions

Why can't I select my screensaver app on Google TV?
Google TV replaced the Android screensaver picker with Ambient Mode, which only accepts Google Photos, Google's Art gallery, or the experimental source. Third-party apps are not listed. Use a launcher with a screensaver override, such as Projectivy or FLauncher, or set it once over ADB.
How do I change the screensaver on Android TV?
Settings → Device Preferences → Screen saver. Any installed app that provides a DreamService appears in the list, and you can also set the idle delay there.
Does changing the screensaver over ADB survive a reboot?
Yes. The setting is written to secure settings and persists across restarts. It can be reset by a system update, in which case you run the same command again.
Can I use my own photos as the screensaver?
Yes. On Google TV, set the Ambient mode source to Google Photos and choose an album. On Android TV, install a photo screensaver app and select it in the Screen saver menu.

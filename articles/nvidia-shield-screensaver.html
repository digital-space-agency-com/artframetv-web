Nvidia Shield screensaver: change it to art

The Nvidia Shield TV runs Android TV, which means it has the classic screensaver menu that newer Google TV devices hide. That makes it one of the easiest boxes to set up. Here is where the setting is and how to put art on it.

Updated 22 November 2026 For Google TV & Android TV

On this page

  1. Open the screensaver settings
  2. Change the screensaver
  3. Set when it starts
  4. Use art as the screensaver
  5. If it does not appear in the list
  6. Common questions

Open the screensaver settings

On a Shield TV, go to Settings → Device Preferences → Screen saver. Menu names can differ slightly between Shield software versions. If you do not see it, look under Settings → Device Preferences for the nearest match.

Change the screensaver

Under Screen saver pick the one you want from the list. The default is Backdrop, which shows photos and scenes. Any screensaver app you install from Google Play appears in the same list, which is the main reason Shield is easier than a Google TV device.

Set when it starts

In the same menu choose When to start and set the idle time. Pick a short delay if you want the TV to behave like a picture on the wall, a longer one if you often pause and come back.

Use art as the screensaver

Install Art Frame TV from Google Play on the Shield, then select it in the Screen saver list. The free version has 30 bundled images in a bevelled mat and frame, no account and no ads. Full steps are in the setup guide.

If it does not appear in the list

Restart the Shield and reopen the Screen saver menu. If it still is not there, see how to change the screensaver on Google TV and Android TV for the launcher and ADB routes.

Common questions

Where is the screensaver setting on Nvidia Shield?
Settings, then Device Preferences, then Screen saver.
How do I change the screensaver start time on Shield?
In the Screen saver menu, choose When to start and select the idle time.
Can I use my own screensaver app on Shield?
Yes. Android TV lists installed screensaver apps in the Screen saver menu, so an app such as Art Frame TV appears there after you install it.
Why is my Shield showing the same screensaver every time?
The default Backdrop screensaver rotates its own images. Choose a different screensaver in the same menu if you want something else.
